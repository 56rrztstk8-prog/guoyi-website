# 郭熠艺术家网站 — 设计规格

## 概述

为艺术家郭熠（Guo Yi）搭建个人网站，域名为 guoyi.com。技术方案使用 Astro 静态站点生成器，先完成中文版，后续再替换为英文版。

---

## 技术方案

- **框架：** Astro 静态站点生成器
- **部署：** 静态 HTML 托管（具体平台待定）
- **i18n：** 先中文，后续用 Astro i18n 路由切换英文
- **无后端：** 不依赖数据库或服务端逻辑

---

## 页面结构

### 1. 主页
- 一张代表作品图片撑满全屏
- "GUO YI" 小字号位于**左上角**，仅英文，像签名
- 鼠标悬停页面**左侧边缘**时，导航菜单从左侧淡入滑出
- 菜单项：作品集 / 新闻 & 展览 / 关于 / 联系方式
- 鼠标移开左侧区域后菜单消失，恢复纯净主页

### 2. 作品集
- 列表式布局，每组作品一张封面图 + 标题 + 简短说明
- 当前作品：《何枝可依》（实验影像）、《Web and Wyrd》（影集）
- 每项可点击进入详情（详情页结构后续确定）

### 3. 新闻 & 展览
- 目前无内容，留空壳占位
- 预留时间线或列表结构，后续填充

### 4. 关于
- 纯文本页面，艺术家自述直接铺开
- 不分段折叠，完整呈现

### 5. 联系方式
- 极简信息：邮箱 + 社交链接
- 不使用联系表单

---

## 视觉方向

- **风格：** 极简东方 — 大量留白、纤细字体、克制配色
- **色调：** 浅色基底，中性色为主（白、米灰、淡灰），让作品和图片成为视觉重心
- **交互：** 左侧隐藏菜单，过渡动画流畅克制

2.触觉
这是一次关于“触碰”的五感练习。从棉花的蓬松到玻璃的冷静，从树干的纹路到脉搏的跳动——我相信，触碰是先于视觉、先于语言的第一种语言，它不会说谎。
在这段影像里，我试图捕捉那些容易被忽略的瞬间：水从指缝流走时的依恋与流失，皮肤泡水后如山脉般的褶皱，荷叶上滚向画面一角的水滴，以及风鼓动衣服时那种轻柔又强硬的包裹感。视频不完全重复文字，而是让影像成为另一种诉说——主观的、片段的、有时甚至矛盾的。
3.你能看见我了吗
以一枚萌生情感的摄像头为主角
在它眼里世界是八音盒的舞台：在小女孩旁边贴上
-枚爱心，为冒烟汽车框起红色警报。它学着人类
去爱，也学着人类不安。直到在一个空无一人的雨
中乐园，它找不到任何目标，却依然感受到一股想
要表达的冲动。这无人接收的喜爱，却成了它存在
的唯一证明。当监控被赋予人性，它便从权力的眼睛转变为陪伴
的眼睛，从“凝视”走向“关怀”。
4.悬而未至 悬而未治
故事发生在“守成纪”——一个未来已被关闭的时代。一切变革均已落地，人们不再仰望星空，转而将旧日幻想制成标本。在那里，对外星人的想象是文化遗产，对未来的渴望是一种需要治疗的精神失调。这部作品真正想触碰的，不是未来，而是现在。悬而未至的未来，悬而未治的渴望。
